# Signals

CTA rail signal aspects, used as the visual metaphor for the course's AI-use
policy. They appear in the "Use of Generative AI" section of the syllabus
(`syllabus_source/syllabus.md`) and in the "Student AI Use" section of
[`docs/faq.md`](../../faq.md).

Signal aspects replace the usual red-yellow-green traffic light because a
traffic light has one lamp and one meaning, while a rail signal stacks two
lamps and tells you about the block you are in *and* the one ahead — which is
closer to how an AI-use policy actually works for an exercise.

The three aspects used:

- **Double red** (`signal-01-stop-stay.svg`) — "stop and stay." No use of
  AI/LLM-based tools.
- **Yellow over red** (`signal-02-caution-main.svg`) — "proceed with caution on
  main route, prepared to stop at next signal." Limited, optional, specific
  use cases; cite what you used. (The `data-science-fun` README calls this one
  "red over yellow"; the artwork is yellow on top.)
- **Double yellow** (`signal-09-caution-restricted.svg`) — "proceed with
  caution at restricted speed." You choose where the tools fit; every use is at
  reduced speed and full attention, and you cite it.

Source: `CTA-rulebook-1973.pdf`, the 1973 CTA rulebook page of color-light
signal aspects. Copied from the sibling `data-science-fun` course repo, which
carries the full set of eleven aspects.
