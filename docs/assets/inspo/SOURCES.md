# Sources — `inspo/`

Inspiration / concept assets for the site's **own** brand (Blue Line Ethics,
`doethics.fun`). Not published site chrome — a scratch/moodboard area.

All files here are **original work** created for this repo. They use the official CTA
**`'L'` route colors only** (Blue Line `#00A1DE`, Red Line `#C60C30`, Sign Grey `#565A5C`),
which the [CTA Trademark Guidelines for Developers](https://www.transitchicago.com/developers/branding/)
explicitly encourage. No CTA logos, marks, or approximations are used — per those
guidelines: *"Don't use any CTA logo … or any approximations thereof."*
